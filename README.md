# PawMail support site

Support and privacy pages for the PawMail iOS app, served by GitHub Pages from the root of `main`.

- `index.html` — support: what PawMail is, three questions, contact
- `privacy.html` — privacy policy (must match the app's privacy manifest and App Store Connect label)
- `style.css`, `mark.png` — shared styles and the paw mark

Source of truth for the copy: the `docs/` folder in the app repo.
